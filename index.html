Data Architecture

法定品目を現場レベルまで細分化

許可上の大分類ではなく、実務で必要な粒度までデータを構造化。
これが既存サイトとの決定的な差になります。

📁 産業廃棄物（法定20品目）
├─汚泥
├─建設汚泥　← 掘削泥水、場所打ち杭汚泥、推進工法汚泥...
├─有機汚泥　← 食品製造汚泥、し尿処理汚泥、製紙汚泥...
├─無機汚泥　← めっき汚泥、研磨汚泥、浄水汚泥...
├─含油汚泥　← タンク底汚泥、洗車汚泥...
└─特殊汚泥　← 受水槽汚泥、ビルピット汚泥、地下湧水汚泥...
├─廃油
├─切削油・潤滑油　← 水溶性、不水溶性、合成油...
├─洗浄油　← 溶剤系、水系、準水系...
└─食用廃油　← 動物性、植物性...
├─廃プラスチック類
├─熱可塑性　← PE, PP, PET, PS, PVC...
└─熱硬化性　← FRP, ウレタン, エポキシ...
├─金属くず / がれき類 / 木くず ...
└─（全20品目 × 細分化 = 200〜300項目）
